MAZEPROOF GUIDE

はじめての迷路検品

画像を読み込む。読み取った壁を目で確かめる。
確認した迷路を検証して、結果を残しましょう。

検品を続けるときは、元の「MazeProof — 迷路の検品室」タブへ戻ってください。新しく始める場合は、右上の「トップへ戻る」から投入画面へ進めます。 元のタブの作業や承認は変わりません。

いま「確認待ち」と出ている方へ

あなたが原画像と照合する段階です。 処理は終わっており、待つだけでは進みません。壁・入口・出口などを確認し、画面下部のチェックを入れて 「確認を承認して検証」を押します。

困ったときは

STEP 01

画像を用意する

矩形の格子に沿った、白い通路・黒い壁の迷路が対象です。PNG / JPEG または PDF を使えます。曲線の迷路や斜めから撮った写真には対応していません。

  1. 「問題画像」で迷路のファイルを選びます。
  2. 解答も調べたい場合は、「解答画像」に同じ迷路へ赤い解答線を描いたファイルを選びます。 問題と解答の向き・行列数をそろえてください。
  3. PDF は「PDF の問題ページ」「PDF の解答ページ」にそれぞれページ番号を入力します。 1 ページ目は「1」。同じ PDF の別ページも選べます。
  4. 「画像を読み込む」を押します。

問題画像だけでも使えます

入口から出口へ行けるか、道順がひとつかを調べられます。解答画像は必須ではありません。 解答画像がないと「解答の合法性」「問題・解答の一致」は未検査になります。

手元に画像がなければ「合成サンプルで試す」から練習できます。 元の構造データを持っている場合は、投入時に「元の構造 JSON とも照合する」を開いて指定できます。通常の画像検品には不要です。

STEP 02

重ね表示を確かめる

重ね表示は、原画像の上に「MazeProof が読み取った迷路」を描くことです。 この読み取った迷路を、判定ではモデルと呼びます。 原画像とモデルが同じかどうかを、人が確かめます。

  • 青緑：読み取った壁
  • 橙色：読み取りに自信がない境界
  • 赤：読み取った解答線
  • S / G：入口 / 出口

画像の上にある「壁・解答の重ね表示」をオフにすると原画像だけを見られます。 オン・オフを切り替え、「拡大」も使って、次を順に照合してください。

  1. 格子と外周。マスの行・列の数が合っているか。認識した外周が迷路の外周に重なっているか。
  2. 壁と通路。黒い壁があるのに読み取られていない場所、通路なのに壁として扱われた場所がないか。
  3. 入口と出口。S と G が意図した入口・出口に付いているか。外周に余分な穴がないか。
  4. 解答画像があるとき。左側の「問題」「解答」を切り替えて、両方の壁と入口・出口を確認します。 解答側では、読み取った赤線が原画像の道順と合い、途切れ・分岐・余分な線がないかも確認します。

「読み取りの確認箇所」が 0 でも、全体の目視確認は必要です。 0 は自動で見つけた不確かな箇所が残っていないという意味で、読み取りが正しい保証ではありません。

STEP 03

読み取りを修正する

原画像と違うところだけ、左側の「修正ツール」で直します。 修正は読み取ったモデルに反映され、元の画像ファイルは変わりません。

橙色の境界
「読み取りの確認箇所」の項目を押して場所を選び、原画像と照合します。 読み取りが合っていれば「境界を確認」を選び、画像上のその境界をクリックします。 違っていれば「壁を反転」でその境界をクリックし、壁と通路を切り替えます。 どちらも確認済みになります。問題・解答の両方で残りを 0 にしてください。 赤線で壁が隠れているなど、原画像から判断できない場合は、推測で承認せず、確認できる画像を用意してください。
細かくてクリックしにくい境界
「座標で境界を編集」を開き、向き・行・列を指定して「確認」または「壁を反転」を押します。 行・列は 0 から数えます。確認箇所の一覧から選ぶと、この座標が自動で入ります。
入口・出口の位置が違う
「入口」または「出口」を選び、画像上の外周の境界をクリックします。 壁の開閉は自動で変わりません。必要なら「壁を反転」で元の開口を閉じ、新しい位置を開けてください。
格子全体がずれている・画像が横向き
「格子・切り出し・回転」を開き、行・列の数と左 x / 上 y / 右 x / 下 y を直して 「この格子で再認識」を押します。座標は画像内のピクセル位置で、外周の壁の中心に合わせます。 横向きなら「右へ90°回転・再推定」を使います。再認識すると壁・解答線の修正と承認は取り消されるので、先に格子を整えます。
解答線の読み取りが違う
「解答」タブで「解答線を消して描き直す」を押し、 「解答をなぞる」を選んで入口から出口までマスの中心を順にクリックします。 最後のマスをもう一度クリックすると一歩戻ります。順序だけが逆なら「解答の向きを反転」を使います。 原画像と照合した後、「赤線の連続性・全体を確認した」にチェックします。

編集を間違えたら「↶ 元に戻す」「↷ やり直す」を使えます。 確認箇所が多い場合は「次の確認箇所」で一覧の続きを表示します。

STEP 04

承認して検証する

承認は「この読み取りが原画像に合っている」と人が確認する操作です。 正解の迷路だと宣言する操作ではありません。到達性や壁横断などは、その後に MazeProof が検証します。

  1. 原画像との照合と修正を終え、「読み取りの確認箇所」を 0 にします。 解答線の確認を求められている場合は、解答側の「赤線の連続性・全体を確認した」にもチェックします。
  2. 画面下部の操作バーで、道順をひとつに限定したい場合は 「唯一解を必須にする」をオンのままにします。
  3. 同じバーの「問題・解答の格子、壁、入口出口、解答線を原画像と照合した」にチェックします。 問題画像だけを入れた場合は、問題の格子・壁・入口・出口の照合で進めます。解答画像を追加する必要はありません。
  4. 同じバーの「確認を承認して検証」を押し、「検証結果」を読みます。 操作バーが見えなければ下へスクロールしてください。

確認の途中で計算結果を見たいとき

「暫定チェック」を使います。読み取った現在のモデルで検査をやり直しますが、人の承認は行いません。 まだ承認していなければ、総合表示は「確認待ち」のままです。

承認後に壁・入口出口・解答線・検証方針などを変更すると、「変更あり・再確認」になります。 元に戻す操作でも承認は復活しません。変更後の状態を照合し、もう一度承認してください。

STEP 05

判定を読む

確認待ち
画像の認識が終わり、人の照合・承認を待っている状態です。待つだけでは進みません。
PASS（暫定） / FAIL（暫定）
未承認のモデルで計算した各検査の結果です。読み取りが違っている可能性があるため、 この表示だけで検品完了とは判断しません。
条件付き PASS
人が確認・承認したモデルについて、指定した検査の条件を満たしました。 「原画像とモデルが一致している」という人の確認が条件です。 認識の見落としや人の確認ミスまで排除した証明ではなく、元の画像・印刷物の完全な正しさを保証しません。 未検査の項目が残っていても表示されるので、各項目も読んでください。
FAIL
承認したモデルに、到達不能・別解・壁横断などの条件違反があります。 理由と「反例・差分・未検査の範囲」を見て、まず原画像との一致を確認します。 原画像も同じなら、迷路や解答そのものを制作側で直す必要があります。
未検査
必要な入力がないなどの理由で、その検査を行っていません。合格という意味ではありません。
「検証結果」の各項目で調べること
画面の項目 意味と範囲
入口から出口 壁を通り抜けずに入口から出口へ到達できるか。
唯一解 同じマスを繰り返し通らない道順が、入口から出口までひとつか。「唯一解を必須にする」をオフにすると、複数の道順があっても合格になり得ます。
解答の合法性 読み取った解答が入口から出口までつながり、壁横断などの違反がないか。解答画像が必要です。
問題・解答の一致 両方の格子・壁・入口出口が同じか。解答画像が必要です。
構造JSONとの一致 問題から読み取った格子・壁・入口出口が、別途指定した元の構造 JSON と同じか。

PDF で調べるのは指定ページの描画された見た目です。 PDF 内部のベクターデータとの一致や、選んでいないページは検証しません。

STEP 06

保存・再開する

自動保存はありません。画面を再読み込みする前、閉じる前、別の検品に移る前に、 画面下部の「作業を保存」を押します。確認の途中でも保存できます。 ブラウザのダウンロード先にファイルが保存されたことを確認してください。 作業ファイルは128MiBまでです。上限を超えると保存せず理由を表示します。 現在の作業は残るので、画面を閉じず、原画像と修正した構造・レポートを別に保管してください。

用途に合わせて保存する
ボタン 保存するもの
作業を保存 mazeproof-work.mazeproof。原画像・修正・設定を含む、作業を再開するためのファイル。
レポート HTML ブラウザで読める検査結果。画像と判定の詳細を含みます。
レポート JSON 他のツールでも扱える検査結果。未承認なら暫定結果として保存されます。
構造 JSON 表示中の「問題」または「解答」のモデル。作業全体を再開するファイルではありません。
重ね画像 PNG 表示中の画像。重ね表示がオフなら、重ねた壁・解答線は含まれません。

続きから再開するには

  1. すでに検品画面なら、必要な作業を保存してから「新しい検品」を押し、確認画面で「続ける」を選ぶと投入画面に戻れます。
  2. 投入画面で「保存した作業を開く」を押し、保存した .mazeproof ファイルを選びます。
  3. 修正した内容が戻ります。承認は引き継がれません。もう一度原画像と照合して承認してください。

保存ファイルは同じ名前でダウンロードされるため、どの迷路か分かる名前にしておくと便利です。 画像は外部へ自動送信されません。作業ファイルと HTML レポートには画像が含まれるので、共有するときは内容を確認してください。

BATCH INSPECTION

まとめて検品する

複数の迷路を読み込み、一覧から順に確認できます。 承認は1件ずつ行います。読み込みが完了しても、まだ合格ではありません。

  1. 投入画面の「複数まとめて検品」を押し、 「問題画像を追加」で複数のファイルを選びます。
  2. 解答がある場合は「解答画像を追加」で選び、 各行の解答欄から対応するファイルを指定します。ファイル名が似ていても自動では組み合わせません。
  3. PDFは各行の問題・解答ページを指定します。同じPDFを複数組に使うときは「行を複製」し、ページ番号を変えます。
  4. 「この組み合わせで読み込む」を押します。 途中で止めるには「一時停止」。現在の1件が終わると止まり、完了分は残ります。 「未処理を読み込む」で続けられます。
  5. 一覧の「確認する」から重ね表示を確認・修正し、承認します。 「一覧へ戻る」「次の確認待ち」で移動できます。移動しても各迷路の修正は残ります。

エラーや暫定の違反があるとき

「表示する項目」で絞り込めます。1件を読めなくても、ほかの迷路の処理は続きます。 ファイルを直して「問題を差し替え」などで選び直し、未処理を読み込んでください。 差し替えた行の修正と承認は取り消されます。PDFの差し替えは1ページ目になるため、別ページを使う場合は新しい一括検品で指定します。

一覧ごと保存して再開する

一覧下部の「一括作業を保存」で、 原画像・各迷路の修正・未処理の項目を.mazeproof-batchにまとめます。 投入画面の「保存した一括作業を開く」から再開し、 「未処理を読み込む」で全件を再認識します。保存されていた承認は引き継ぎません。

「一覧レポート JSON」「一覧レポート HTML」には各件の結果・確認待ち・エラーを残せます。 レポートは再開用のファイルではありません。個別画面の「作業を保存」はその1件だけの保存です。

1回に100件、原画像の合計32MiBまで。一括作業ファイルは128MiBまでです。 同じPDFや解答を複数行に指定した場合も、行ごとに容量を数えます。 途中で保持量の上限に達したら、一括作業を保存してから件数を分けてください。 自動保存はないため、画面を閉じる前にダウンロードを確認してください。

WHEN YOU NEED HELP

困ったときは

「確認を承認して検証」が押せない
画面下部の照合チェックが入っているか、問題・解答の両方に未確認の橙色境界が残っていないかを確認します。 解答側の赤線確認も必要な場合があります。承認の手順を順に確認してください。
承認時に入口・出口や開口の修正を求められる
入口・出口の指定と、外周の壁の開閉を確認してください。承認できる形になるまで、モデルの不正を先に直す必要があります。 「暫定チェック」で理由を確認できます。
読み込みをやめたい・別の画像でやり直したい
読み込み中は「取り消す」を押せます。別の画像を入れるには、必要な作業を保存して 「新しい検品」へ進みます。置き換えの確認画面で「戻る」を押せば作業を続けられます。
画像を読めない・「上限に達しました」と出る
画面の理由を確認し、対応する PNG / JPEG / PDF でやり直します。1 ファイル 25 MiB、 描画後 2,000 万画素、PDF は 20 ページまでです。暗号化 PDF は読めません。 余白の切り出しや小さなファイルで試す場合も、細い壁が消えないことを確認してください。
再読み込み・サーバー終了で作業が消えた
保存した .mazeproof ファイルを開き直してください。保存していなければ原画像からやり直します。 「起動時に表示された専用URLから開き直してください」と出た場合は、サーバー起動時の URL を使います。
